# expected: M_NO_POCKET and M_POCKET_SITTING TenDayRule; M_INCOMPAT Incompatibility and CongressNotImpeachable;

# expected: and under SpecPresidentActs (the President's diligence in the clock's place); NoBehaviour is COUNTEREXAMPLE under FairSpec.
#
# The module is three machines over one Executive: legislation (Bills), the Executive with impeachment
# and appointments (Offices), and Article V (Amendments). Their product is 634,620 states with all on, so
# each row switches on the machine its property reads and sets the other two empty (Bills={}, Offices={},
# Amendments={}). Legislation reads only the President's presence and the session, and Article V reads
# nothing, so no action of a property's machine reads a variable of a machine switched off: a mutation
# whose check lies in a machine switched off is inert in that row, which then records only that the
# property holds with Mut set to it. Those cells are M_UNICAMERAL..M_POCKET_SITTING against the
# Executive, appointment and Article V properties; M_INCOMPAT, M_VP_RECHECK, M_CONSENT_RECHECK and
# M_PRO_FORMA against the legislative and Article V properties; M_RATIFY_VOTE and M_SUFFRAGE against all
# but ArticleV. The mutations of the Executive itself act in every row. The theorems in
# Constitution_proof.tla, whose hypotheses omit these mutations, cover every such cell at every constant.
# (Run with both machines on, M_INCOMPAT against Bicameralism alone is 2,756,172 states.)
# TypeOK, Safety and the deadlock audit run with all three on; TypeOK under each mutation runs with the
# machine the mutation changes.
#
# Constants: one member per House (enough for every vote check, since each mutation removes its threshold
# and a vote of none then carries); two persons eligible to be President, so two can alternate and three
# terms are reachable under M_XXII; four States, the fewest at which three-fourths is not every State.
# The one amendment, a1, touches equal suffrage, so it needs every State whatever M_RATIFY_VOTE does;
# m-ratifyvote-artv and w-none-ratfewer therefore make it an ordinary amendment (SuffrageAmendments={}).
# ElectionsBound (terms <= 3) binds only under M_XXII, whose state space is otherwise infinite.
#
# DEADLOCK: Convene or Adjourn is always enabled, so no state is terminal; d-none-deadlock checks it.
