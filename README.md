# gov-tla

A TLA+ model of the *procedural* core of the United States Constitution.

This is an exercise, not law. The Constitution is, for the most part, a set of
state machines gated by supermajorities. These specs model those machines,
check with TLC that every rule the text states is one the model actually
depends on, and prove with TLAPS that the rules hold.

## How the specs are written and checked

The modules follow the method in the `writing-tla-specs-and-proofs` skill:
write each property so that it is **local**, model-check it at small
constants, prove it, and keep the evidence in files that a script
regenerates.

The skill is in
[`.claude/skills/writing-tla-specs-and-proofs/`](.claude/skills/writing-tla-specs-and-proofs/SKILL.md),
where Claude Code loads it for work in this repository. It is a copy,
unchanged, of the skill on TOPAK's `main`:
[`skills/writing-tla-specs-and-proofs`](https://github.com/scottcochran/TOPAK/tree/main/skills/writing-tla-specs-and-proofs),
merged in TOPAK PR #29 (merge commit `a157659`; the skill's last change is
`7771a8a`), licensed CC BY 4.0. If the skill changes on TOPAK's `main`,
copy it again and update this paragraph. Where the skill and this README
differ, the README describes how this repository does it: one generic row
generator (`scripts/tlc_rows.py`) instead of a run script per module, and
pin files instead of a tracked jar.

- **Local properties.** One action could break each property, and that
  action's guard decides whether it does. Each property is one of three
  kinds:
  - a state predicate whose inductive step is that guard;
  - a flag the violating step would raise (`tenDayBreach`, `payCut`,
    `warWithoutStatute`);
  - a record written once and checked against the guard of the step that
    wrote it (a case's verdict, jury and venue, recorded at trial).
- **Mutations.** Every module has a constant `Mut`. `Mut = "none"` is the
  text. Each other value removes exactly one check, and the module header
  names the property that removal must break. Where they exist, the
  mutations are real earlier law, such as the Articles of Confederation,
  *Humphrey's Executor*, *Chisholm v. Georgia* or the legislative veto
  before *Chadha*. TLC must find a counterexample for every mutation
  against every property it breaks, and none against any other.
- **Witnesses.** Each `Never…` property says that something the text
  allows never happens: a law passed over a veto, a pocket veto, a court
  abolished under a sitting judge. TLC must find each one violated, which
  shows the model reaches those states. Without witnesses, a property
  could hold only because the state it forbids is unreachable.
- **Proofs.** `<Module>_proof.tla` extends the module without editing it.
  It proves each safety property as `Spec => []P`, assuming only that the
  mutations which break `P` are absent. It also proves `SafeAlways` under
  `Mut = "none"`, and has one lemma per mutation saying what that mutation
  admits.
- **Evidence.** All of it is in `results/`, generated by `scripts/` and
  never edited. Each file is dated and names the checker or prover, and
  every module it covers, by sha256.

The words matter. **Checked** means TLC explored every reachable state at
the constants in the row list. **Proved** means TLAPS discharged every
obligation for every value of the constants the module's named
assumptions admit. **Sampled** means random simulation found no error,
and is never cited as a check. None of these is a claim about law or
practice.

| Module | TLC rows (all as expected) | Mutations | Witnesses | Proof obligations (all proved) |
|---|---|---|---|---|
| `Constitution.tla` | 302 | 19 | 14 | 1,092 |
| `Judiciary.tla` | 451 | 23 | 12 | 2,150 |
| `Executive.tla` | 208 | 14 | 19 | 814 |
| `Government.tla` | 565 | 14 | 15 | 1,543 |

Every flip test fails as required: with one mutation hypothesis flipped
to `Mut = "M_X"`, each proof breaks in the lemma of the property that
mutation must break.

What is **not** proved, and why:

- **Liveness properties** (`PresentedBillsResolve`, `ActingEventuallyEnds`,
  `UnconstitutionalEdgesAreStruck`) are checked by TLC, not proved. Each is
  a leads-to quantified over bills, agencies or edges, and the pinned
  prover has no sound route for a quantified leads-to. This is the skill's
  known limit.
- **`Government.tla`'s global reachability claims** are checked, not
  proved. They are stated over `Reach`, a recursive function the prover
  has no fixpoint theory for. Each one's local form is proved.
- **Witnesses and counterexamples** are existential, and stay with TLC.

For a self-assessment by Claude of what these specs and proofs are, and
are not, good for, see [`docs/ASSESSMENT.md`](docs/ASSESSMENT.md).

## Modules

Congress: legislation, the Executive with appointments and impeachment,
and Article V.

| `M_PRO_FORMA` | recess appointments only in a recess | the NLRB appointments struck in *Noel Canning* (2014) | `RecessAppointmentsInRecess` |

`Safety` is the conjunction of the thirteen properties in the "Breaks"
column. Four of them are new flags (`TenDayRule`, `ConvictionTwoThirds`,
`XXVBothHouses`, `RecessAppointmentsInRecess`). Three existing ones
changed meaning:

- `Bicameralism` now covers every bill presented, returned or enacted.
- `Presentment` now includes two-thirds on each House's override vote.
- `TwoTermLimit` is no longer implied by `TypeOK`.

Witnesses (each violated):

- law by signature, by lapse and by override, and a pocket veto;
- conviction with disqualification;
- a VP nominee and an officer nominee disqualified while pending;
- a recess appointment, and a President elected twice;
- VP succession and XXV §2 confirmation;
- ratification after each proposal route, and ratification by fewer
  than every State.

**Liveness.** `FairSpec` adds `TimeRuns`, under which the ten days run
out. `PresentedBillsResolve` holds under `FairSpec`. It fails under
`Spec`, and under `SpecPresidentActs` (fairness on the President
instead), because the Presidency can be vacant. `NoBehaviour` is
violated under `FairSpec`, which shows `FairSpec` has a behaviour. No
state is terminal.

**Rows.** Each row switches on only the machine its property reads. With
all three machines on, `M_INCOMPAT` against `Bicameralism` alone is 2.8
million states. A mutation whose check lies in a machine that is
switched off does nothing in that row. The row list says so, and the
proof covers those cells, since each theorem excludes only the mutations
that break it.

### `Executive.tla` — Article II and the administrative state

The Constitution creates no bureaus. It refers to "executive Departments"
and their "principal Officer[s]", but every department, agency and
commission is a creature of statute, so `Init` has none. Congress
attempts statutes from the constant `Charters`. The rows use
`KnownCharters`, six real statutes:

- an executive department, CBO and the Sentencing Commission, which the
  checks in `Chartered` admit;
- the FTC of *Humphrey's Executor*, the FEC of 1974 and the Comptroller
  General under Gramm–Rudman–Hollings, which they refuse.

| Art. I §6 cl. 2 — Incompatibility Clause | `EligibleOfficer`, `Incompatibility` |

Witnesses (each violated):

- an agency created and one abolished;
- a head confirmed and one removed by the President, and Congress
  removing its own officer;
- an acting officer serving and one timing out;
- Congress appointing a non-executing body's officer, a

### `Government.tla` — the authority graph

The other three modules model what each branch does. This one models how
authority runs *between* them: a directed, labelled multigraph over the
People, the States, the Constitution, the three branches, the Vice
President, and the agencies and inferior courts Congress creates. Edges
come in two layers:

- **Grant** — where authority comes from: `Power` (vesting clauses,
  enabling acts), `Select` (elections, nomination, consent), `Amend`
  (Articles V, VII).
- **Control** — one holder acting on another's exercise of power: veto,
  override, purse, impeachment, removal, review, pardon.

Every exercise of authority is the firing of an edge in the graph at that
moment, by its holder, under its condition (a sitting Congress, a seated
President, a pending case, a presidential trial). Firing can reshape the
graph:

- statutes add and remove edges and nodes;
- amendments rewrite text edges: XVII moves the Senate from the States to
  the People, and XXV lets the President nominate a Vice President whom
  Congress confirms, and adds the inability edges;
- courts sever unconstitutional statutory edges.

The graph claims are about reachability, which no single action decides.
Each claim is therefore stated twice:

- a **local form**, which one action could break and that action's guard
  decides, proved;
- the **global form**, kept under its old name and checked by TLC, which
  follows from the local forms beside it.

| Claim | Local form (proved) | Global form (checked) |
|---|---|---|
| Outside the People, the States and the Vice Presidency the grant layer is acyclic: every grant edge but the President's nomination of a Vice President runs forward along Constitution → Congress → Vice President → Executive → Judiciary → statute | `GrantFollowsChainExceptXXV` | `GrantCyclesPassThroughPeopleStatesOrVP` |
| The President–Vice President loop is the only grant cycle among government bodies, present exactly while XXV is in force | `NominationLoopIffXXV` (with the above) | `OnlyGrantCycleIsXXV` |
| Every branch, agency and court traces back to the People | `NamedPathsFromPeople`, `EveryBodyIsCreatedByLaw` | `PowerTracesToPeople` |
| Power (as opposed to office) reaches the government from the People only through the Constitution | `PeoplePowerGoesThroughConstitution` | `ConstitutionIsTheOnlyDoor` |
| The control layer is complete among the branches, and so cyclic | `MutualChecks` | `ControlLayerIsCyclic` |
| Congress has more control edges onto each branch than it has onto Congress | `LegislativePrimacy` | — |
| Only the People and the States write the Constitution | `ConstitutionWrittenByPeopleAndStates` | — |
| Article V is always in the graph | `ArticleVStands` | — |
| The text layer is the 1789 text as amended; text edges change only by Article V | `TextFollowsArticleV`; `TextChangesOnlyByArticleV` (action property) | — |
| Statutory edges change only by presentment, override or judicial review | `StatutesChangeOnlyByLawOrCourt` (action property) | — |

| `M_CONGRESS_AMENDS` | (a constant, not a guard) XXV also gives Congress an Amend edge into the text | — | `ConstitutionWrittenByPeopleAndStates`, `GrantFollowsChainExceptXXV`, `GrantCyclesPassThroughPeopleStatesOrVP`, `OnlyGrantCycleIsXXV` |
| `M_NO_ARTV` | (a constant, not a guard) XXV also repeals Article V | — | `ArticleVStands` |

Witnesses (each violated):

- an agency created and abolished, and a court established;
- a forbidden edge enacted, and an edge of each doctrine struck;
- XVII and XXV ratified, a Vice President seated by nomination, and a
  contested inability;
- a court abolished under a sitting judge, and a bill on the desk while
  Congress is adjourned.

**Liveness.** `FairSpec` adds two weak-fairness conditions for every
challengeable edge:

- `LitigantsSue`, on `Sue(e)`: the People's obligation, since someone
  injured sues;
- `CourtsDecide`, on `Review(e)`: the Judiciary's, since a pending case
  is decided.

`SpecNoSuit` and `SpecNoRuling` each drop one of them, and the liveness
property fails under each.

**Rows.** Four configurations:

- no agency or court, with every amendment;
- one inferior court;
- one agency whose enabling act draws the forbidden edges, with and
  without the `LawRowsBound` constraint.

Every row uses `VIEW Unrecorded`: no action reads `last`, so states that
differ only in `last` are identified. `Government.cfg` holds the full
constants, whose exhaustive state space is very large. One row samples
it.

#### A claim TLC refuted

`Government.tla` first folded the Vice President into the Executive. It
claimed that, with the People and the States set aside, the grant layer
is acyclic and runs strictly down the chain Constitution → Congress →
Executive → Judiciary. With the Vice President as a node of its own, TLC
refutes both claims in two steps:

```
State 1: <Initial predicate>
State 2: <Propose>   amendment = [XVII |-> "None", XXV |-> "Proposed"]
State 3: <Ratify>    amendment = [XVII |-> "None", XXV |-> "Ratified"]
Error: Invariant GrantCyclesPassThroughPeopleOrStates is violated.
```

Section 2 of the Twenty-fifth Amendment lets the President nominate a
Vice President, and the Vice President may succeed the President. So
Executive → Vice President → Executive is a cycle of authority that
never passes through the People or the States. It is how Gerald Ford
became President in 1974, nominated by Nixon in 1973 and confirmed by
Congress, and how Ford then chose Nelson Rockefeller. Before XXV the
claims hold: a vacant Vice Presidency simply stayed vacant.

The original properties are kept, unchanged, as
`GrantCyclesPassThroughPeopleOrStates` and `GrantFollowsChain`. The rows
`r-o-none-acyclic` and `r-o-none-chain` expect, and get, a counterexample
under `Mut = "none"`. They replace `Government_strict.cfg`.

## Findings

What TLC and the prover found while these specs were written. Each is in
a dated results file or in the module history.

**Checks made at nomination but not at confirmation.** TLC found these
while the modules were first written. Each is now a mutation that
restores the bug.

- `Constitution.tla` — a Vice-Presidential nominee could be impeached,
  convicted and disqualified while pending, then confirmed anyway
  (`M_VP_RECHECK`).
- `Judiciary.tla` — a Chief Justice nominee could be confirmed to a
  district court while pending, then confirmed as Chief Justice, and sit
  on two courts (`M_CHIEF_RECHECK`).

**Two claims the earlier `Judiciary.tla` made, which TLC refutes.**

- `ExceptionsHonoured`, as a state predicate, failed when Congress
  excepted a head while an appeal in it was pending. That is *Ex parte
  McCardle* itself. The property is now checked at the step that takes
  the appeal, with `ExceptionsBindPending` and `Dismiss` for the step
  that decides it.
- `AppealsCourtsAreAppellate` failed when a closed case's district court
  was abolished and its identifier re-established as a court of appeals.
  It now reads the tier recorded at filing.

**One the prover found.** In `Executive.tla`, `M_SAMEPERSON` (one person
as both President and Vice President) also breaks `Disqualification`.
Convicting that person passes the presidency to themself. The proof's
inductive step for `Convict` needed President ≠ VP, and TLC confirms the
counterexample.

**One mutation that changes nothing.** In `Government.tla`, `M_RECHECK`
removes the re-check of a bill's applicability at enactment. It reaches
exactly the states of `none` (the row asserts the count). The re-check
is redundant in this model, because only one bill is in flight at a time
and nothing changes its precondition between passage and enactment.

**The graph claims of 1789 and the XXV cycle**: see "A claim TLC refuted"
above.

## Running

Install the pinned tools once:

```bash
./install-tla.sh            # TLC; checks tools/tla2tools.jar against tools/TLC-PIN
tools/install-tlaps.sh      # TLAPS (Linux x86_64, macOS arm64); compared with tools/TLAPS-PIN
```

Check, prove and audit a module:

```bash
python3 scripts/tlc_rows.py rows/Executive-rows.txt -j 2    # results/Executive-results-<date>.txt
python3 scripts/proof_results.py Executive --threads 2      # results/Executive-proof-results-<date>.txt
python3 scripts/flip_test.py Executive --threads 2 M_HUMPHREY M_FECA ...
python3 scripts/proof_sync.py                               # IN SYNC / STALE for every results file
```

- **`scripts/tlc_rows.py`** runs every row of a row list with `-workers 1`.
  Each row is one TLC run with a `Mut` value, a spec, a property, the
  verdict it must give, and any constants it overrides. The script writes
  the dated results file only if every row is as expected, and never
  overwrites one. A rerun that reproduces a file says so; one that
  differs is written beside it with a letter suffix.
- **`scripts/proof_results.py`** runs `tools/tlapm --cleanfp --strict`
  with a throwaway cache. It writes the proof results file only if every
  obligation is proved.
- **`scripts/flip_test.py`** flips one mutation hypothesis in a scratch
  copy of the proof. It requires the proof to fail in a statement that
  carries that hypothesis.
- **`scripts/proof_sync.py`** compares every results file's digests with
  the tree, and the checker and prover with their pins. With `--run`, it
  re-checks each stale proof.

On a 4-core machine shared with other runs, each row list took between 20
minutes and two hours at `-j 2`.

**Pins.** `tools/tlapm` refuses a prover that is not the one pinned in
`tools/TLAPS-PIN` unless `TLAPM_UNPINNED=1`, and `tlc_rows.py` does the
same for TLC with `TLC_UNPINNED=1`. The 1.6.0-pre release tag is rebuilt
upstream, so a fresh install may not match the pin. A results file made
with another build names that build, and moving the pin is the record of
the change.

**Configs.** The `.cfg` files describe a larger model: three
Representatives, two Senators, two agencies, every amendment. They exist
for the visualization tools and ad hoc runs, and set `Mut = "none"`.
Exhaustive runs at those constants are very large. To sample them:

```
java -cp tools/tla2tools.jar tlc2.TLC -simulate num=100000 -depth 40 -workers auto -config Judiciary.cfg Judiciary.tla
```

A run like this is **sampled**, not checked. Only the row lists' results
files are evidence.

## Visualization Tools

Three scripts draw what the specs do. A tic-tac-toe board has a few
thousand states, so its whole state graph can be dumped once and drawn;
these specs have millions, so each script instead runs TLC on a small
wrapper module that bounds the run (a depth `CONSTRAINT` for breadth-first
search, a length `INVARIANT` for simulation) and parses the states TLC
prints. The modules and their `.cfg` files are used as they are; the
wrappers live in a temporary directory.

Every state is drawn as **what differs from the initial state**, with
records and functions flattened to paths such as `bill.b1.status` or
`agency.ag1.head`, and coloured by who acted to reach it:

| Color | Who acted |
|-------|-----------|
| Yellow | Initial state |
| Light Blue | Congress (either house): bills, overrides, consent, statutes |
| Orange/Salmon | The President or the executive: signing, vetoes, nominations, removals |
| Green | The courts: decisions, appeals, judicial review |
| Red/Coral | Impeachment and trial |
| Plum | The People and the States: elections, Article V, filing suit |
| Gray | Time, death, resignation |

winget install graphviz

### visualize_states.py

Draws the state graph of one module to a limited depth: every behaviour of
up to `depth` steps from the initial state.

**Usage:**
```bash
uv run python visualize_states.py [module] [depth]
```

- `module` (optional): `Constitution` (default), `Executive`, `Judiciary` or `Government`
- `depth` (optional): steps from the initial state (default: 2 for
  `Constitution`, 1 for the others, whose fan-out is much wider)
- `--merge N`: at the deepest level, collapse `N` or more sibling states
  reached by the same action into one dashed node that lists what they
  share and which variables vary (default 4; `0` draws every state)
- `--all-edges`: also draw, dotted, edges that do not go one level deeper
- `--keep-dot`: keep TLC's raw dump as `{module}_states_depth{N}.dot`

**Examples:**
```bash
uv run python visualize_states.py                   # Constitution, 2 steps
uv run python visualize_states.py Government        # the authority graph's first moves
uv run python visualize_states.py Judiciary         # many ways to set exceptions, merged
uv run python visualize_states.py Executive 2 --merge 0   # all 43 states
```

**Output:**
- `{module}_depth{N}.png`, e.g. [`Constitution_depth2.png`](Constitution_depth2.png)
  and [`Government_depth1.png`](Government_depth1.png)
- Console output: states by depth, and transitions by action

| Module | Depth 1 | Depth 2 |
|--------|---------|---------|
| Constitution | 7 | 39 |
| Executive | 8 | 43 |
| Judiciary | 147 | 2,803 |
| Government | 65 | 1,182 |

(Distinct states within that many steps of the initial state, with the
configs in this repository.)

### simulate_trace.py

Simulates and visualizes one random behaviour. TLC chooses every step
(`-simulate` with a seed, so a run can be repeated) and stops after
`--steps` steps, or earlier if no action is enabled.

**Usage:**
```bash
uv run python simulate_trace.py [module] [seed] [--steps N]
```

- `seed` (optional): random seed for a reproducible behaviour; without
  one a seed is chosen and printed
- `--steps` (optional): length of the behaviour (default: 20)

**Examples:**
```bash
uv run python simulate_trace.py                     # random Constitution run
uv run python simulate_trace.py Constitution 42     # reproducible run
uv run python simulate_trace.py Government 3 --steps 40
```

**Output:**
- Console output showing each step, who acted, and what it changed
- `{module}_trace.png` or `{module}_trace_seed{N}.png`, e.g.
  [`Constitution_trace_seed42.png`](Constitution_trace_seed42.png): one
  node per state, the lines changed by that step in bold and marked `▸`

**Sample console output** (`Constitution 42`):
```
Step 1: ProposeByConvention  (People and States (elections, Art. V, suits))
  amend.a1.status: None → Proposed
  amend.a1.route: None → Convention
--------------------
Step 2: Elect  (People and States (elections, Art. V, suits))
  president: NoOne → p2
  vicePresident: NoOne → p1
  terms.p2: 0 → 1
--------------------
Step 3: VicePresidentVacates  (Time, death, resignation)
  vicePresident: p1 → NoOne
```

`Government.tla`'s `Sue` and `Exercise` sit under `\E e \in edges`, which
TLC cannot split into separate actions, so it reports them as `Next`; the
scripts tell them apart by the edge recorded in `last`.

### authority_graph.py

`Government.tla`'s state *is* a graph, so this script draws the `edges`
variable itself: nodes for the People, the States, the Constitution, the
branches and the agencies and courts in existence; edges colored by kind
(Power blue, Select green, Amend purple, Control gray), dashed if put there
by statute rather than the Constitution.

**Usage:**
```bash
uv run python authority_graph.py [seed] [--steps N] [--layer grant|control|all]
```

- No seed: the graph of 1789, [`Government_authority.png`](Government_authority.png)
- With a seed: simulate `--steps` steps (default 40) and draw the graph as
  it ends, marking edges added by amendment (bold), edges repealed (dotted
  gray), statutory edges under challenge (red, ⚖) and the edge that fired
  last, e.g. [`Government_authority_seed6.png`](Government_authority_seed6.png)
  (XXV ratified and XVII proposed, an agency created, and two of its
  statutory edges challenged in court)
- `--layer` draws only the grant layer or only the control layer

### authority_poster.py

The same graph as a 24 × 36 in print poster, for the founding graph or for
any later year:
[`Government_authority_poster_1789.pdf`](Government_authority_poster_1789.pdf)
and [`Government_authority_poster_2026.pdf`](Government_authority_poster_2026.pdf)
(previews: [1789](Government_authority_poster_1789.png),
[2026](Government_authority_poster_2026.png)).

**Usage:**
```bash
uv run python authority_poster.py               # 1789: the founding graph
uv run python authority_poster.py --year 2026   # as amended through 2026
```

`--year` applies every amendment in the model ratified by that year: XVII
(1913) moves the Senate's Select edge from the States to the People, and XXV
(1967) lets the President nominate a Vice President whom Congress confirms,
and adds the inability edges. What each amendment
changes comes from the model: the script compares the text edges just before
and just after the `Ratify` step in simulated behaviours. Only the years are
written into the script, in `RATIFIED`, and it stops if the model gains an
amendment that has no year there.

Instead of one tangle of edges, the poster separates the two layers.
The grant layer is drawn as a chain read top to bottom. The control layer
draws one arrow per direction between branches, its width the number of
checks, with the checks listed beside it. Headline numbers (edge counts,
Congress's checks against the other branches', grant cycles among
government bodies: none in 1789, the President–Vice President loop from 1967)
are computed from the graph, and the edges come from TLC.
The script stops if the model has an edge the poster's layout does not
place.

Writes `Government_authority_poster_YEAR.html`, then renders the PDF and PNG if
Node.js and Playwright are installed; otherwise print the HTML to PDF at
24 × 36 in from a browser.

## Ideas for next steps

- Refinement mappings from `Constitution.tla`, `Executive.tla` and
  `Judiciary.tla` to `Government.tla`, so every action in the detailed
  modules is shown to be the firing of an edge in the authority graph.
- Judicial review as a holding that voids a law in `Constitution.tla`.
- Staggered Senate classes (Art. I §3 cl. 2).
- Named-member votes instead of counts, to express conflict-of-interest rules
  such as the Chief Justice presiding at a presidential trial.
- Liveness proofs. The three leads-to properties are quantified over bills,
  agencies or edges. They need either one instance at a time or a second,
  kernel-checked prover, as the skill describes.
- A fixpoint theory for `Reach`, so that `Government.tla`'s global
  reachability claims can be proved from their local forms rather than
  only checked.
- `Constitution.tla` rows with every machine on, so that every
  mutation-against-property cell is checked as well as proved. This needs
  a bigger machine: one such row is 2.8 million states.
- Print a row's `constraint=` in its results file. Today it appears only
  in the row list, which the results file names by digest.
